# CodePen version of the gallery

Paste the three files into one pen: `index.html` -> HTML pane, `style.css` -> CSS pane, `script.js` -> JS pane (no preprocessors, no external libraries).
Data and media come from `https://autonomousq.github.io/claudeskills-media/` (GitHub Pages, CORS enabled), so the pen stays current. Optional pen settings: title "claudeskills Motion Graphics Gallery"; add `<meta name="viewport" content="width=device-width, initial-scale=1">` in Settings > HTML > Head.
Regenerate after a gallery change: `python3 motion-graphics/scripts/build-codepen.py --media <claudeskills-media checkout>` (claudeskills repo).
